## 반박 2건 부기 (기각됐지만 기록)

- **`PUT /api/profile` 에서 `usableTime` 을 빠뜨리면 빈 문자열로 덮인다** — 서버 동작 자체는 재현됨. 그러나 앱의 모든 호출부가 두 필드를 항상 함께 보내 사용자 경로로는 도달 불가. 계약 위생 차원에서 m17 과 함께 400 으로 바꿀 수 있다.
- **타임아웃이 SIGTERM 한 번뿐이라 자식이 안 죽으면 가드가 무기한 잠긴다** — Node 의미론은 사실(리눅스 실측: SIGTERM 무시 자식 + `spawn({timeout})` → `close` 영영 안 옴). 그러나 `claude` CLI 는 SIGTERM 에 정상 종료해 재현 불가. m3(취소) 수정 시 `killSignal` 을 SIGKILL 로 승격하는 2단 종료를 함께 넣으면 방어가 된다.
