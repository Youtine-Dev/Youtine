  - A: **앞부분 일치** — `CONCAT('%', ?, '%')` → `CONCAT(?, '%')`(별칭별). '세라마이드 → 세라마이드엔피'·'판테놀 → 판테놀(비타민B5)' 는 살고 '우레아 → 이미다졸리디닐우레아'·'알코올 → 세테아릴알코올' 은 빠진다. 한 줄. **(추천)**
  - B: 정확 일치(`sameIngredient`)로 JS 재필터 — 가장 엄격하지만 '세라마이드엔피' 같은 변형이 빠져 사전 → 제품 흐름이 자주 비게 된다(주석이 부분 일치를 고른 이유).
  - C: 현행 유지.
- **Q2. 모든 단계를 건너뛴 수행** (m2)
  - A: **기록하지 않는다** — 완료 화면이 "모든 단계를 건너뛰어 기록하지 않았어요"를 보이고 시작 표시만 지운다. 홈·루틴 카드·주간 스트립·기록 목록이 한 번에 일관된다. **(추천)**
  - B: 기록하고 '수행함'으로 센다(현행) + 홈 달성률 카드만 '기록 있음'으로 맞춘다 — "0단계 완료 = 오늘 완료"가 남는다.
- **Q3. 첫 주 달성률** (m1)
  - A: **루틴 생성일부터 센다** — 이번 주·지난주 분모를 `createdAt` 이후로 자르고, 지난주에 루틴이 없었으면 비교 문구를 숨긴다. 단 `PUT /api/routines` 가 행을 지웠다 다시 넣어 `created_at` 이 편집 때마다 리셋되므로 **재삽입 시 기존 `created_at` 을 보존**하는 수정이 함께 필요하다. **(추천)**
  - B: 생성 주에는 지난주 비교만 숨긴다(이번 주 25–50% 표시는 남는다).

- 성분 추출 중 모달 닫기·Esc 가 막혀 최대 300초 '갇힘' — 뒤로가기·새로고침·하단 탭이 있어 막다른 길은 과장(닫기 차단은 진행 중 결과 유실 방지 의도).
